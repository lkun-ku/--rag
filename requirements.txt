# ---- 扫描件 OCR（ROADMAP 任务 2.3；方案已验证，代码尚未接入）-------------
# 为什么不用 unstructured hi_res（实测结论）：
#   hi_res 需要 Tesseract 语言包（本机 tessdata 为 0 个，中文需 chi_sim）+
#   pytesseract + unstructured_pytesseract + YOLO 版面模型，共 4 项额外依赖；
#   而 RapidOCR 只要下面 3 个纯 pip 包（onnxruntime 上面已装）。
# 实测效果：中文行级 6/6 命中、平均置信度 0.980、2.5s/页；
#           OCR 文本经现有管道可产出 category=='content' 的块（可被检索）。
# 注：仅扫描件会触发它，有文本层的 PDF 仍走 pymupdf4llm。
